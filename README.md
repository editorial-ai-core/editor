
# AI Медиаконсультант

Это веб-приложение представляет собой инструмент на базе AI для журналистов и редакторов. Оно помогает анализировать тексты, находить идеи для статей и создавать новостные материалы, следуя принципам ясности и структуры "перевернутой пирамиды".

## ✨ Возможности

- **"Я редактор" (Анализ и отчет):** Оценивает текст на "пену" (канцеляризмы, оценочные суждения) и проверяет структуру лида на соответствие 7 ключевым вопросам.
- **"Нет идеи" (Поиск тем):** Генерирует 5 актуальных инфоповодов, используя интернет или предоставленный контекст.
- **"Есть повод" (Написание текста):** Создает готовую короткую новость на основе инфоповода, очищая его от "пены" и структурируя по принципу "перевернутой пирамиды".

## 🚀 Как запустить проект

Этот проект настроен для работы без сложной сборки (no-build setup) и может быть запущен на любом статическом хостинге.

### 1. API Ключ

Для работы приложения необходим API ключ от **Google Gemini API**.

Вам нужно убедиться, что в вашей среде (например, в настройках хостинга или в переменных окружения вашего сервера) установлена переменная `API_KEY`. Код автоматически использует `process.env.API_KEY`.

### 2. Локальный запуск

Чтобы запустить проект на вашем компьютере:
1.  Склонируйте репозиторий.
2.  Откройте папку с проектом в терминале.
3.  Запустите любой простой веб-сервер. Например, если у вас установлен Python:
    ```bash
    python -m http.server
    ```
    Или, если вы используете VS Code, можете установить расширение **Live Server** и запустить проект с его помощью.
4.  Откройте сайт в браузере по адресу, который покажет сервер (обычно `http://localhost:8000`).

### 3. Размещение на хостинге

Просто загрузите все файлы из этого репозитория в корневую директорию вашего сайта на хостинге (например, Hostinger). `index.html` является входной точкой.

## 🛠️ Технологии

- **React:** Библиотека для создания пользовательского интерфейса.
- **TypeScript:** Типизированный язык программирования.
- **Tailwind CSS:** CSS-фреймворк для быстрой стилизации.
- **Google Gemini API:** Искусственный интеллект для обработки текста.
- **Babel Standalone:** Используется для компиляции TSX/JSX кода прямо в браузере, что позволяет обходиться без шага сборки.

## 📁 Структура файлов

- `index.html`: Главный HTML-файл, который загружает все скрипты и стили.
- `index.tsx`: Точка входа в React-приложение.
- `App.tsx`: Основной компонент приложения, содержащий всю логику интерфейса.
- `services/geminiService.ts`: Файл для взаимодействия с Gemini API.
- `components/`: Директория с переиспользуемыми React-компонентами (`icons.tsx`, `MarkdownRenderer.tsx`).
- `metadata.json`: Информация о приложении.
